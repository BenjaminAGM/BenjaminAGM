<h2 align="center">🏋️ TrainTrack</h2>

<p align="center">
  <i>Aplicación móvil para seguimiento de entrenamiento y bienestar</i>
</p>

**TrainTrack** es una aplicación móvil desarrollada en equipo enfocada en el seguimiento del entrenamiento y bienestar de los usuarios.

La aplicación permite registrar diferentes indicadores asociados al estado físico y al entrenamiento, facilitando el seguimiento de variables como **fatiga, sueño y percepción del esfuerzo (RPE)**.

El proyecto utiliza una arquitectura separada entre aplicación móvil, backend y base de datos.

<br>

### ✨ Funcionalidades

- 📋 Registro de indicadores diarios de bienestar
- 💪 Seguimiento de rutinas de entrenamiento
- 😴 Registro de sueño y fatiga
- 📊 Registro de percepción del esfuerzo mediante RPE
- 🦾 Seguimiento del descanso muscular
- 🔄 Comunicación entre frontend y backend mediante API REST
- 🗄️ Persistencia de datos
- 📱 Aplicación móvil desarrollada con Flutter
